# English display name

The home-page name “Wang Xin” uses Great Vibes by Robert Leuschke, distributed with the site as `fonts/GreatVibes-Regular.ttf`. It is a display-name exception to the site's Times New Roman rule; other English text, including the academic profile, retains its existing academic typography.

Official project: https://github.com/googlefonts/great-vibes

Google Fonts metadata: https://github.com/google/fonts/blob/main/ofl/greatvibes/METADATA.pb

Font asset: https://fonts.gstatic.com/s/greatvibes/v21/RWmMoKWR9v4ksMfaWd_JN-XC.ttf

License: SIL Open Font License 1.1, supplied in `fonts/GreatVibes-OFL.txt`.

The font is served locally; visitors do not need a font installation or a request to Google Fonts. Chinese display lettering is unchanged.
